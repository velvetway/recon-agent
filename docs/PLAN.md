# План: от скоупа до списка CWE/CVE

Цель системы: по скоупу программы bug bounty собрать разведданные, отфильтровать
их, сопоставить с каталогом слабостей MITRE CWE и известными CVE и выдать
список «актив → слабость → доказательство → что проверять».

```
скоп (txt/yaml) → scope.yaml → scope-guard
      ↓
инструменты (профили: passive / light / active)
      ↓
Neo4j — единый источник правды
      ↓
фильтр шума → экспорт архива (raw / by-tool / by-asset + manifest)
      ↓                                   ↓
версии → NVD/OSV → CVE → CWE        досье → LLM (внешняя, потом локальная)
      ↓                                   ↓
      └──── CWE-guard + проверка evidence ┘
                      ↓
      отчёт: актив → CWE/CVE → доказательства → ссылка в атлас
                      ↓
               обратно в граф
```

Принципы:

- **Граф — источник правды.** Архив не хранится отдельно, а экспортируется из
  графа, поэтому они не расходятся.
- **Детерминированное — без LLM.** Версии → CVE и базовые правила сигнал → CWE
  работают без модели. LLM только расширяет и приоритизирует.
- **Ничего без доказательства.** Каждый вывод ссылается на наблюдения из архива,
  а каждый CWE-ID проверяется по каталогу (CWE-guard), так же как цели
  проверяет scope-guard.
